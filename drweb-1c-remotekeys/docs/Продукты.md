# Продукты и скидки Dr.Web (справочник для заполнения)

В исходном документе список продуктов и скидок дан ссылкой, а конкретные ID и
допустимые комбинации (продукт × скидка × срок × количество объектов) берутся из
**актуального прайс-листа Dr.Web** и партнёрского портала. Ниже — заготовка;
заполните её реальными значениями (или пришлите список — впишу).

## Типы защищаемых объектов и параметры

| Тип | Код | Параметр запроса |
|---|---|---|
| Рабочие станции | `w` | `computers` |
| Серверы | `s` | `servers` |
| Почтовые ящики | `m` | `mailboxes` |
| Трафик | `t` | `traffic` |
| Пользователи | `u` | `users` |

- `traffic` и `mailboxes` взаимоисключающи.
- Имя параметра `computers` соответствует типу `w` (workstations).

## Периоды

Формат `period`: `1m`, `3m`, `6m`, `12m`, `24m` и т.д. (`Nm` — число месяцев; в
`getserialinfo` встречается также `1d` — дни). Допустимые для конкретного продукта
периоды — в прайс-листе.
