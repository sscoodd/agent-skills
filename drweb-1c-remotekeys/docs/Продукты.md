# Продукты и скидки Dr.Web

Dr.Web поддерживает две схемы задания продукта при генерации:

- **старая** — `product=ID` + количества `computers`/`servers`/`mailboxes`/`traffic`/`users`;
- **НЛ (новое лицензирование), версия с базовыми лицензиями** — `bls=` + `comp<БЛ>=` +
  `obj<БЛ>=` (см. ниже). Рекомендуется как более практичная.

Полные комбинации и цены — в прайс-листе Dr.Web / партнёрском портале. Ниже —
идентификаторы из документации Dr.Web.

## Типы защищаемых объектов (старая схема)

| Тип | Код | Параметр запроса |
|---|---|---|
| Рабочие станции | `w` | `computers` |
| Серверы | `s` | `servers` |
| Почтовые ящики | `m` | `mailboxes` |
| Трафик | `t` | `traffic` |
| Пользователи | `u` | `users` |

- `traffic` и `mailboxes` взаимоисключающи.
- Имя параметра `computers` соответствует типу `w` (workstations).

## Продукты (старая схема, `product=`)

| product (ID) | Название | Тип | Объекты | Примечание |
|---|---|---|---|---|
| 624 | Dr.Web Security Space | home | computers | Пример из квик-старт гайда |
| 46 | (Security Space) | home | — | Встречается как `pid` в примере getserialinfo |

> Разные ID могут относиться к разным схемам/редакциям лицензирования. Для бизнеса
> практичнее НЛ-схема (базовые лицензии) — см. ниже.

> Формат логина партнёра — `avt_NNNNNN` (как на https://pa.drweb.com/).

## Скидки (`discount=`)

Из интерфейса подсчёта цены НЛ (буква — суффикс скидки в коде продукта `pcode`):

| discount (ID) | Условие | Суффикс |
|---|---|---|
| 21 | Нет скидки (новая лицензия) | A3 |
| 1 | Продление | B3 |
| 8 | Продление + дозакупка | D3 |
| 2 | Миграция | A4 |
| 16 | Образованию/медицине | A1 |
| 14 | Продление Образованию/медицине | B1 |
| 18 | Продление + дозакупка Образованию/медицине | D1 |

> Прим.: в старом описании `renew=yes` соответствует скидкам `1` и `16`. В НЛ-прайсе
> `16` — образование/медицина. При сомнении сверяться с прайс-листом.

## НЛ: базовые лицензии и компоненты (версия с БЛ)

Продукт задаётся как комбинация базовых лицензий (`bls`), их компонент (`comp<БЛ>`) и
количеств объектов (`obj<БЛ>`), где `<БЛ>` — ID базовой лицензии. Пример:
`bls=263:314&comp263=68&comp314=6:48&obj263=10&obj314=30`. Для дозакупки в `obj`
через двоеточие передаётся прежнее число: `obj263=35:30`.

### Для бизнеса

| Продуктовая группа | Базовая лицензия (`bls`) | Компоненты (`comp`) |
|---|---|---|
| Desktop Security Suite (рабочие станции) | Комплексная защита — `263` | Центр Управления — `68` (Криптограф `180283` — недоступен) |
| Server Security Suite (серверы) | Антивирус — `300` | Центр Управления — `6` |
| Mail Security Suite (почта) | Антивирус — `314` | Центр Управления — `6` (Антиспам `48`, SMTP proxy `64` — недоступны) |
| Gateway Security Suite (шлюз) | Антивирус — `315` | Центр Управления — `6` (Антиспам `174` — недоступен) |
| Mobile Security Suite (моб. устройства) | Комплексная защита — `342` | Центр Управления — `6` |
| Комплект для малого и среднего бизнеса | `764` | — |
| Комплект для образовательных учреждений | `1993` | — |

| Продуктовая группа | Базовая лицензия (`bls`) | Компоненты (`comp`) |
|---|---|---|
| Продукты для дома (рабочие станции) | Dr.Web Security Space — `372` | (Криптограф `153` — недоступен) |

> Перечёркнутые в оригинале позиции (здесь помечены «недоступен») недоступны для заказа.

## Периоды

Формат `period`: `1m`, `3m`, `6m`, `12m`, `24m`, `36m` и т.д. (`Nm` — число месяцев; в
`getserialinfo` встречается также `1d`). Для продления с дозакупкой оставшийся срок
передаётся через двоеточие: `period=12m:1m`.

## Ещё не хватает (по продуктам)

- **`nl-products-and-licdata.html`** — плоский «Референс-список продуктов НЛ» (без БЛ):
  может содержать готовые коды продуктов (`pcode`). У нас есть рекомендованная BLS-версия.
- **Каталог кодов продуктов** — https://pa.drweb.com/licensing/product_codes/ (маппинг
  `pcode` ↔ продукт; нужен для `price_by_pcode` и разбора заказов).
