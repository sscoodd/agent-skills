# Дополнительные интерфейсы Dr.Web (расширение утилиты)

Помимо базовой генерации/блокировки/информации (см. [API-Справка.md](API-Справка.md)),
партнёрский API Dr.Web включает интерфейсы ниже. Здесь — их спецификация как основа
для следующих этапов утилиты. Во всех — авторизация `login`/`pwd` (POST), логин `avt_NNNNNN`.

Ядро (`МодульОбъекта.bsl`) уже позволяет обращаться к произвольным параметрам генерации
через `ДополнительныеПараметры`, поэтому **НЛ-генерация возможна уже сейчас** (передать
`bls`/`comp<БЛ>`/`obj<БЛ>`). Остальные интерфейсы — отдельные endpoint'ы, их стоит
добавить в ядро отдельными методами.

## 1. Генерация НЛ (базовые лицензии)

Тот же endpoint, что и обычная генерация — `https://f2.drweb.com/remotekeys/`
(`act=serial`). Вместо `product=`/`computers=`/… передаётся комбинация:

| Параметр | Значение | Пояснение |
|---|---|---|
| `bls` | `263:314` | ID базовых лицензий через двоеточие |
| `comp<БЛ>` | `comp263=68`, `comp314=6:48` | компоненты базовой лицензии (через двоеточие) |
| `obj<БЛ>` | `obj263=10`, `obj314=30` | количество объектов по базовой лицензии |

Для дозакупки количество прежних объектов — через двоеточие: `obj263=35:30`.
ID базовых лицензий и компонент — в [Продукты.md](Продукты.md). Дом и бизнес в одном
запросе не комбинируются.

## 2. Быстрое продление серийного номера

**`POST https://f2.drweb.com/remotekeys/quick+renew/`**

| Параметр | Значение |
|---|---|
| `login` / `pwd` | учётные данные |
| `serial` | серийный номер зарегистрированной, действующей, ещё не продлённой лицензии |

Создаёт продление на продукт исходной лицензии сроком на 1 год (+ остаток срока).
Ответ — XML, HTTP всегда 200 (успех/ошибка — в `response.status`):

```xml
<response timestamp="1466074231">
  <newserial>83LT-TQ6Q-983C-N5P8</newserial>
  <pcode>LHW-BK-12M-1-B3</pcode>
  <status>ok</status>
</response>
```

Ошибка:

```xml
<response timestamp="1466073656">
  <status>error</status>
  <details>Access denied</details>
  <message>403 403 okay</message>
</response>
```

## 3. Цена продления

**`https://f2.drweb.com/renew+price/`** — протокол/представление как у продления.

| Параметр | Значение | Обяз. |
|---|---|---|
| `login` / `pwd` | учётные данные | да |
| `serial` | серийный номер | да |
| `cur` | валюта, напр. `RUB` | нет |
| `period` | `12m` / `24m` / `36m` | нет |

```xml
<response timestamp="1466434269"><currency>RUB</currency><status>ok</status><price>774.00</price></response>
```

## 4. Цена НЛ (по базовым лицензиям)

**`https://products.drweb.com/aj+price/`**

Продукт задаётся как в НЛ-генерации (`bls` / `comp<БЛ>` / `obj<БЛ>`), плюс:

| Параметр | Значение |
|---|---|
| `discount` | ID скидки (см. [Продукты.md](Продукты.md)) |
| `period` | срок, напр. `12m` (или `12m:1m` для дозакупки) |
| `cur` | валюта |
| `detailed` | `t` — детализация по позициям |

Ответ — XML. Итог:

```xml
<result>17528.00</result>
```

Детализированный (`detailed=t`):

```xml
<result>
  <item><pcode>LBW-AC-12M-10-A3</pcode><sum>10296</sum></item>
  <item><pcode>LBP-AAC-12M-30-A3</pcode><sum>15699.84</sum></item>
</result>
```

### Цена по коду продукта

**`https://f2.drweb.com/pa/price_by_pcode/?code=LBW-BC-12M-10-A3`** → ответ **JSON**.
Коды продуктов — https://pa.drweb.com/licensing/product_codes/.

## 5. Информация о заказах (выгрузка для отчётов)

**`POST https://pa.drweb.com/api/orders+info/`** (при авторизации — только POST; либо
сессия партнёрского портала). Без параметров — заказы за последние 24 часа.

| Параметр | Значение | Пояснение |
|---|---|---|
| `dealer` | `123123123` | карточки партнёров для выборки (несколько — через нецифровой разделитель) |
| `nodealer` | `123123123` | исключить партнёров |
| `period` | `24h` | период в часах |
| `date_from` / `date_to` | `2022-03-01` | альтернатива периоду |
| `oids` | `123:456:…` | конкретные ID заказов |
| `serials` | `ABCD-1234-5678-DEFG:…` | конкретные серийные номера (только из ваших заказов) |
| `compact_exprice` | `1`/`0` | компактная выгрузка запрайсовых позиций |
| `pstatus` | `1`/`0` | партнёрский статус (текущий) для цепочки поставки |

Ответ — JSON: `status` = `ok`/`error`, при `ok` в `data` — список событий:

```json
{ "status": "ok",
  "data": [ { "event": "new_order", "order_id": 123123123, "created": "2022-03-23 12:46:47",
              "cur": "RUB",
              "partner": { "title": "…", "partner_id": 232323, "inn": 1234567890, "kpp": 2394234, "country": "RU" },
              "contents": [ { "item_id": 234456789, "product_code": "LBW-BC-12M-10-A3",
                              "title": "Dr.Web Desktop Security Suite, Нет скидки, 12 мес.",
                              "price": 10890, "quantity": 1, "price_per_one": 10890, "partner_price": 9500 } ] },
            { "event": "order_cancelled", "order_id": 345345345, "created": "2022-04-01 12:10:20" } ] }
```

События: `new_order`, `order_cancelled`. `partner` — автор заказа; `contents` — позиции
(`product_code`, `title`, `price` РРЦ, `partner_price` с учётом скидки).

## 6. Привязка данных пользователя постфактум (домашние продукты)

**`https://f2.drweb.com/api+bind+druser+serial/`** (GET или POST). Только для домашних
продуктов. Досыл данных пользователя уже выданной лицензии (не путать с бизнес-анкетой
`ui_*`, которая передаётся при генерации).

| Параметр | Значение | Обяз. |
|---|---|---|
| `login` / `pwd` | учётные данные | да |
| `mode` | `act` | да |
| `serial` | серийный номер | да |
| `phone` | телефон пользователя | — |
| `date` | дата продажи (`2019-06-25`) | — |

Ответ — JSON, HTTP 200: `{"status":"ok","data":"Done"}` либо
`{"status":"error","data":"<пояснение>"}`.

## Ещё не предоставлено

- **`nl-products-and-licdata.html`** — плоский референс-список НЛ (без БЛ); может содержать
  готовые коды продуктов. У нас есть рекомендованная BLS-версия — этого достаточно.
- **Плоский список всех `pcode`** — страница «Коды продуктов» на портале это интерактивный
  калькулятор, а не перечень; правила формирования кода получены (см. [Продукты.md](Продукты.md)).
