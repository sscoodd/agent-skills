# Сборка внешней обработки `.epf`

Из исходников (`src/МодульОбъекта.bsl`, `src/МодульФормы.bsl`) внешняя обработка
собирается в 1С:Конфигураторе или 1С:EDT. Ниже — сборка в **Конфигураторе**
(платформа 8.3.1x и новее, управляемое приложение; проверялось под 1С:Бухгалтерия
предприятия 3.0).

> `.epf` — бинарный контейнер, его собирает только Конфигуратор/EDT. Поэтому в
> репозитории лежат исходные модули и эта инструкция, а не готовый файл.

## Шаг 1. Создать внешнюю обработку

1. Конфигуратор → **Файл → Новый → Внешняя обработка**.
2. Имя: `DrWebRemoteKeys`. Синоним: `Dr.Web: генерация лицензий`.

## Шаг 2. Вставить модуль объекта

1. Правой кнопкой на обработке → **Открыть модуль объекта**.
2. Вставить содержимое `src/МодульОбъекта.bsl` целиком.

## Шаг 3. Создать основную форму и её реквизиты

Добавить форму: правой кнопкой на обработке → **Формы → Добавить → Форма обработки**,
сделать её основной.

На закладке **Реквизиты** формы создать перечисленные реквизиты. Основной реквизит
`Объект` (тип `ВнешняяОбработкаОбъект.DrWebRemoteKeys`) создаётся платформой
автоматически — его оставляем.

| Реквизит | Тип | Примечание |
|---|---|---|
| `Логин` | Строка | Логин партнёра |
| `Пароль` | Строка | На элементе формы включить **Режим пароля** |
| `Продукт` | Строка | ID продукта (`product`) |
| `Период` | Строка | `1m`, `3m`, `12m`, `24m` … |
| `Скидка` | Строка | ID скидки (`discount`) |
| `Компьютеры` | Число (целое ≥ 0) | `computers` |
| `Серверы` | Число (целое ≥ 0) | `servers` |
| `ПочтовыеЯщики` | Число (целое ≥ 0) | `mailboxes` |
| `Трафик` | Число (целое ≥ 0) | `traffic` |
| `Пользователи` | Число (целое ≥ 0) | `users` |
| `КомментарийЗаказа` | Строка | `comment` |
| `ИдентификаторПозицииЗаказа` | Строка | `order_item_id` |
| `СерийныйДляПродления` | Строка | `renewserial` |
| `Тестовый` | Булево | `testing=yes` |
| `ФорматXML` | Булево | `format=xml` (по умолчанию Истина) |
| `ДополнительныеПараметры` | ТаблицаЗначений | Колонки: `Имя` (Строка), `Значение` (Строка) |
| `СерийныйДляБлокировки` | Строка | Для операции блокировки |
| `ПричинаБлокировки` | Строка | `reason` |
| `СерийныйДляИнформации` | Строка | Для запроса информации |
| `РезультатТекст` | Строка (многострочная) | Вывод результата |

Колонки таблицы `ДополнительныеПараметры` добавляются в дереве реквизита
(правой кнопкой на реквизите → Добавить колонку): `Имя` и `Значение`, обе тип Строка.

## Шаг 4. Разместить элементы на форме

Перетащить реквизиты из списка на форму (можно выделить все и перетащить — платформа
создаст поля автоматически). Рекомендуемая группировка (не обязательна):

- **Учётные данные**: `Логин`, `Пароль`.
- **Генерация**: `Продукт`, `Период`, `Скидка`, `Компьютеры`, `Серверы`,
  `ПочтовыеЯщики`, `Трафик`, `Пользователи`, `КомментарийЗаказа`,
  `ИдентификаторПозицииЗаказа`, `СерийныйДляПродления`, `Тестовый`, `ФорматXML`,
  таблица `ДополнительныеПараметры`.
- **Блокировка**: `СерийныйДляБлокировки`, `ПричинаБлокировки`.
- **Информация**: `СерийныйДляИнформации`.
- **Результат**: `РезультатТекст` (поле ввода, многострочный режим, растянуть).

Для `РезультатТекст` включить свойство **МногострочныйРежим** и по желанию
**ТолькоПросмотр**.

## Шаг 5. Добавить команды и кнопки

На закладке **Команды формы** создать три команды и назначить им обработчики
(имена обработчиков должны совпасть с процедурами в модуле формы):

| Команда | Заголовок кнопки | Обработчик |
|---|---|---|
| `Сгенерировать` | Сгенерировать | `Сгенерировать` |
| `Заблокировать` | Заблокировать | `Заблокировать` |
| `ПолучитьИнформацию` | Информация по номеру | `ПолучитьИнформацию` |

Перетащить команды на форму (кнопки) — рядом с соответствующими группами или на
командную панель формы.

## Шаг 6. Вставить модуль формы

Открыть **модуль формы** и вставить содержимое `src/МодульФормы.bsl` целиком.
В нём уже есть `ПриСозданииНаСервере` и обработчики команд.

## Шаг 7. Проверка синтаксиса и сохранение

1. **Текст → Синтаксический контроль** в обоих модулях (Конфигуратор проверит код).
2. **Файл → Сохранить как…** → сохранить `DrWebRemoteKeys.epf`.
3. Открыть в 1С:Предприятии: **Файл → Открыть…** → выбрать `.epf`
   (или подключить как дополнительную обработку в БОльшинстве конфигураций через
   *Администрирование → Печатные формы, отчёты и обработки → Дополнительные отчёты и обработки*).

## Точки проверки (если синтаксический контроль что-то подчёркивает)

- **URL-кодирование.** В `МодульОбъекта.bsl`, функция `КодироватьЗначение`, вызов
  `КодироватьСтроку(…, СпособКодированияСтроки.URLВКодировке)`. Если в вашей версии
  платформы имя члена перечисления иное — подставьте доступный вариант
  `СпособКодированияСтроки`.
- **HTTPS.** Используется `Новый ЗащищенноеСоединениеOpenSSL`. Доступно на актуальных
  платформах 8.3; если сервер за прокси — задайте `Настройка.Прокси` (тип `ИнтернетПрокси`).
- **Права клиента.** Обращения к сети выполняются на сервере; для внешних обработок
  в защищённом режиме может потребоваться разрешение на работу с интернетом.

## Альтернатива: загрузка из файлов / 1С:EDT

Если удобнее собирать обработку из файлов (`Конфигуратор → Обработка → Загрузить из
файлов`) или вести проект в 1С:EDT — скажите вашу точную версию платформы, и можно
подготовить соответствующую структуру XML для прямой загрузки (её схема зависит от
версии платформы).
