# Коды ошибок интерфейса Dr.Web

Один и тот же HTTP-код может означать разное в разных операциях. Расшифровка в
обработке зависит от действия (`ОписаниеКодаОшибки` в `src/МодульОбъекта.bsl`).

При сбое соединения (сеть/таймаут/TLS) обработка возвращает `КодОшибки = -1` и текст
исключения в `ОписаниеОшибки`.

## Генерация серийных номеров (`act=serial`)

| Код | Значение |
|---|---|
| 403 | Access denied — ошибка авторизации (вероятно неверны логин/пароль) |
| 405 | Only POST method is supported — метод запроса отличен от POST |
| 412 | Недопустимое сочетание продукта, скидки, срока, количества объектов |
| 500 | Внутренняя необработанная ошибка сервиса |
| 503 | Service is locked — сервис временно недоступен, повторите попытку |
| 590 | No or invalid product id — неверный/отсутствующий `product` |
| 592 | Отсутствуют или не валидны данные о пользователе (бизнес-анкета) |
| 594 | No or invalid `computers` |
| 595 | No or invalid `mailboxes` |
| 596 | No or invalid `amount` |
| 598 | Invalid `discount` |
| 600 | No or invalid `traffic` |
| 601 | Нельзя одновременно задавать `traffic` и `mailboxes` |
| 603 | Invalid Server ID — ключа с таким Server ID нет |
| 614 | Указан неверный ключ (серийный номер) |
| 615 | Лицензия заблокирована |
| 616 | Несовместимые продукты при продлении |
| 617 | Неверный период для продления |
| 618 | Неверный период для продления |
| 619 | Несовместимые количества защищаемых объектов при продлении |
| 620 | Указан неверный ключ (серийный номер) |
| 625 | Уже продлён |
| 626 | Не продлеваемый продукт |
| 628 | Несовпадение количества объектов при продлении (превышает в новой лицензии) |
| 629 | Ошибка входа в эксклюзивный режим для переданного `order_item_id` |
| 630 | Неверная цепочка поставки (`for_partner_next`): нет связи или доступа |
| 633 | Продлевается результат разбивки |
| 634 | Попытка продлить неактивированную лицензию |

## Блокировка серийного номера (`act=blockserial`)

| Код | Значение |
|---|---|
| 200 | Успех |
| 401 | Серийный номер уже зарегистрирован (нужно блокировать ключ, а не номер) |
| 403 | Access denied — ошибка авторизации дилера |
| 404 | Key is not found — ключ не найден |
| 405 | Only POST method is supported |
| 412 | Не указана причина (см. сообщение в status_line) |
| 591 | No key id — не передан параметр key |
| 624 | Блокировка лицензии партнёром после истечения отчётного периода |

## Информация по серийному номеру (`getserialinfo`)

Обычно отвечает `200` с XML `<serialattrs>`; признаки состояния — в полях `valid`,
`blocked`, `registered`, `expired`. Ненулевой HTTP-код трактуется как ошибка транспорта.
