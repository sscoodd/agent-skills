# drweb-1c-remotekeys — контекст проекта для агента

Внешняя обработка **1С:Предприятие 8.3** (управляемое приложение, целевая конфигурация —
1С:Бухгалтерия предприятия 3.0) для партнёрского API Dr.Web: генерация/блокировка/проверка
серийных номеров, продление, цены, заказы, привязка пользователя. Эта папка — отдельная
утилита; правила корневого CLAUDE.md про skills/ к ней не относятся.

## Текущее состояние (обновляй при изменениях)

- **Ядро готово**: `src/МодульОбъекта.bsl` — все методы API реализованы и не зависят
  от формы (список методов — в `docs/Доп-интерфейсы.md`, таблица «метод ядра»).
- **Форма (v1)**: `src/МодульФормы.bsl` — три операции (генерация/блокировка/информация).
  Реквизиты формы — таблица в `docs/СборкаОбработки.md`; дизайн — `docs/Интерфейс.md`.
- **`.epf` ещё не собран** — это ближайшая задача: выполнить `docs/EDT-Хендофф.md`
  (проверка стека → сборка обработки из src/ → экспорт XML в `build-src/` →
  сборка `.epf` → коммит).
- **UI-этап 2 (после сборки)**: вкладки Продление / Цены / Заказы / Постфактум поверх
  готовых методов ядра.

## Конвенции кода

- Встроенный язык 1С, идентификаторы и комментарии — по-русски; экспортные методы
  документированы шапками в стиле СП (см. существующий код).
- Сеть — только на сервере; POST для всего, где передаётся `pwd` (не светить пароль
  в query/логах). Пароль нигде не хардкодится, не логируется, не выводится в результат.
- Ответы API разнородны: где HTTP-код значащий (генерация/блокировка), а где всегда
  200 + `status=ok/error` в теле (продление, цены, постфактум, заказы) — при правках
  сохраняй эту логику (`ОбработатьXMLОтветСоСтатусом`/`ОбработатьJSONОтветСоСтатусом`).
- Карта ошибок зависит от операции (один HTTP-код — разные смыслы), см. `docs/КодыОшибок.md`.

## Проверки

- Стек: `tools/check-edt-stack.sh` (Linux/macOS/Git Bash) или `tools/check-edt-stack.ps1`
  (Windows PowerShell).
- Синтаксический контроль модулей в Конфигураторе/EDT — обязателен перед коммитом.
- Точка внимания: `СпособКодированияСтроки.URLВКодировке` в `КодироватьЗначение()` —
  если платформа подчёркивает имя, подставить доступный вариант перечисления.
- Используемые API платформы: `ЗащищенноеСоединениеOpenSSL`, `HTTPСоединение`,
  `ПостроительDOM`, `ЧтениеJSON`/`ПрочитатьJSON`, `СтрШаблон` — нужна 8.3.10+.

## Чего не делать

- Не менять хосты/endpoint'ы API без сверки с `docs/` (источники перечислены в
  `docs/Доп-интерфейсы.md`).
- Не добавлять секреты (логины/пароли/серийники) в код, доки, коммиты и логи.
- Не коммитить тестовые серийные номера, полученные без `testing=yes`.
