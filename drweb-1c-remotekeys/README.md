# Dr.Web: генерация лицензий — внешняя обработка 1С

Внешняя обработка для **1С:Предприятие 8.3** (управляемое приложение; проверялась под
**1С:Бухгалтерия предприятия 3.0**) для работы с партнёрским интерфейсом Dr.Web
автоматизации генерации лицензий:

- генерация лицензионных серийных номеров (`act=serial`, включая НЛ по базовым лицензиям);
- блокировка серийного номера (`act=blockserial`);
- получение информации по серийному номеру (`getserialinfo`);
- продление серийного номера (`quick+renew`) и расчёт цены продления;
- расчёт цены НЛ (`aj+price`) и цены по коду продукта (`price_by_pcode`);
- выгрузка информации о заказах (`orders+info`);
- привязка данных пользователя постфактум (`api+bind+druser+serial`).

Разбор API — в [docs/API-Справка.md](docs/API-Справка.md), смежные интерфейсы — в
[docs/Доп-интерфейсы.md](docs/Доп-интерфейсы.md).

## Как получить `.epf`

`.epf` — бинарный контейнер, поэтому в репозитории лежат **исходные модули** и
инструкция по сборке, а не готовый файл. Сборка в 1С:Конфигураторе занимает
~10–15 минут: см. **[docs/СборкаОбработки.md](docs/СборкаОбработки.md)** (создать
внешнюю обработку → вставить модуль объекта → создать форму с реквизитами → добавить
команды → вставить модуль формы → синтаксический контроль → сохранить `.epf`).

## Использование

### Интерактивно (форма обработки)

Открыть обработку в 1С:Предприятии, заполнить логин/пароль партнёра и параметры
генерации, нажать «Сгенерировать». Для отладки включить флажок «Тестовый»
(`testing=yes`) — такие номера не сохраняются на стороне Dr.Web. Результат (серийные
номера, атрибуты, тело ответа) выводится в поле результата.

### Программно (из другого кода 1С)

Ядро (`МодульОбъекта.bsl`) не зависит от формы — его можно вызывать напрямую или
скопировать в общий модуль конфигурации.

```bsl
// Обработка, подключённая как файл .epf:
Обработка = ВнешниеОбработки.Создать("C:\drweb\DrWebRemoteKeys.epf");

Настройка = Обработка.НоваяНастройка("ЛОГИН_ПАРТНЁРА", "ПАРОЛЬ_ПАРТНЁРА");
Настройка.Тестовый = Истина;   // тестовый режим на время отладки
Настройка.Формат   = "xml";    // "xml" (умолч.) | "json" | "mime"
Настройка.КодыПродавцов = Истина; // satcodes=yes — коды для продавцов (только в XML)

Параметры = Обработка.НовыеПараметрыГенерации();
Параметры.Продукт    = "624";  // ID продукта (624 = Dr.Web Security Space, см. docs/Продукты.md)
Параметры.Период     = "12m";
Параметры.Компьютеры = 1;

Результат = Обработка.СгенерироватьСерийныеНомера(Настройка, Параметры);
Если Результат.Успех Тогда
	Для Каждого Позиция Из Результат.Позиции Цикл
		Сообщить(Позиция.Серийный + ?(ЗначениеЗаполнено(Позиция.КодПродавца), " / satcode: " + Позиция.КодПродавца, ""));
	КонецЦикла;
Иначе
	Сообщить("Ошибка " + Результат.КодОшибки + ": " + Результат.ОписаниеОшибки);
КонецЕсли;
```

Бизнес-анкета (для корпоративных продуктов) и цепочка поставки:

```bsl
Параметры.АнкетаКлиента.ui_inn     = "7714533600";
Параметры.АнкетаКлиента.ui_cntry   = "RU";
Параметры.АнкетаКлиента.ui_orgname = "ООО ""Клиент""";

Параметры.ЦепочкаПоставки.for_partner = "avt_12345"; // ИНН/номер карточки/логин

// Любой параметр, не вынесенный отдельно:
Параметры.ДополнительныеПараметры.Вставить("keytype", "...");
```

Блокировка и информация:

```bsl
Рез1 = Обработка.ЗаблокироватьСерийныйНомер(Настройка, "XXXX-XXXX-XXXX-XXXX", "Ошибочный заказ");
Рез2 = Обработка.ПолучитьИнформациюПоСерийному(Настройка, "XXXX-XXXX-XXXX-XXXX");
// Рез2.Атрибуты — Соответствие с полями <serialattrs> (period, valid, blocked, ...)
```

Продление, цены, заказы и привязка пользователя (см. [docs/Доп-интерфейсы.md](docs/Доп-интерфейсы.md)):

```bsl
// Быстрое продление: новый серийник в Результат.СерийныеНомера, pcode — в Атрибуты
РезП = Обработка.ПродлитьСерийныйНомер(Настройка, "XXXX-XXXX-XXXX-XXXX");

// Цена продления (Атрибуты: price, currency)
РезЦ = Обработка.ЦенаПродления(Настройка, "XXXX-XXXX-XXXX-XXXX", "RUB", "12m");

// Цена НЛ по базовым лицензиям (aj+price)
ПЦ = Обработка.НовыеПараметрыЦеныНЛ();
ПЦ.Период = "12m"; ПЦ.Скидка = "21"; ПЦ.Валюта = "RUB"; ПЦ.Детально = Истина;
ПЦ.Параметры.Вставить("bls", "263:314");
ПЦ.Параметры.Вставить("comp263", "68");
ПЦ.Параметры.Вставить("obj263", "10");
ПЦ.Параметры.Вставить("obj314", "30");
РезН = Обработка.ЦенаНЛ(Настройка, ПЦ); // Атрибуты.result или Данные (позиции {КодПродукта, Сумма})

РезК = Обработка.ЦенаПоКоду(Настройка, "LBW-BC-12M-10-A3"); // JSON -> Данные

// Заказы за период (JSON -> Данные, поле data)
ПЗ = Обработка.НовыеПараметрыЗаказов(); ПЗ.Период = "24h";
РезЗ = Обработка.ПолучитьЗаказы(Настройка, ПЗ);

// Привязка пользователя постфактум (домашние продукты)
РезB = Обработка.ПривязатьПользователя(Настройка, "XXXX-XXXX-XXXX-XXXX", "9101234567", "2026-08-15");
```

## Требования

- Платформа 1С:Предприятие 8.3 (актуальный релиз), управляемое приложение.
- Исходящий HTTPS к `f2.drweb.com` и `gsi.drweb.com` (порт 443). При работе через
  прокси задать `Настройка.Прокси` (тип `ИнтернетПрокси`).
- Действующая учётная запись партнёра Dr.Web (логин/пароль партнёрского портала).

## Безопасность

- Логин/пароль партнёра нигде не хардкодятся: задаются в форме или передаются в код.
  Пароль не выводится в результат и не логируется обработкой. На поле пароля в форме
  включён режим пароля.
- Запросы к `f2.drweb.com` идут методом **POST** (пароль не попадает в query-строку и
  журналы прокси).
- Рекомендуется не хранить серийные номера и учётные данные в открытом виде.

## Что нужно уточнить/заполнить

Продукты, скидки, НЛ-базовые лицензии и формат кода продукта сведены в
[docs/Продукты.md](docs/Продукты.md); все интерфейсы (генерация, НЛ, продление, цены,
заказы, привязка пользователя постфактум) описаны. Осталось некритичное:

- **Допустимые комбинации** продукт × скидка × срок × объекты — из прайс-листа Dr.Web.
- **Точный формат `for_partner`/`supplier`** — у курирующего менеджера Dr.Web.
- **Плоский референс-список НЛ** (`nl-products-and-licdata.html`) — необязателен, есть BLS-версия.

Смежные интерфейсы (НЛ-генерация, продление, цены, заказы, постфактум) — в
[docs/Доп-интерфейсы.md](docs/Доп-интерфейсы.md). Полный список пробелов — в конце
[docs/API-Справка.md](docs/API-Справка.md).
